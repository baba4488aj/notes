Choose the Method

GIVEN velocity field u,v,w:
Continuity -> derivatives, divergence.
Acceleration -> material derivative.
Rotation -> curl; stresses -> strain rate.
Pressure gradient -> Euler or Navier-Stokes.

GIVEN stream function psi:
Differentiate for u,v; use psi differences for flow per width.

GIVEN pressure taps, nozzle, tank, jet, siphon:
Choose stations -> continuity -> Bernoulli or extended mechanical-energy balance.

GIVEN plate, belt, film, shear, speed profile:
Simplify x-momentum -> 2 integrations -> actual boundary conditions.

GIVEN round laminar pipe:
Cylindrical momentum, Hagen-Poiseuille, radial integral.

GIVEN rough pipe, fittings, turbulence:
Re -> Darcy friction factor -> major/minor head losses.

GIVEN startup or liquid-column acceleration:
Unsteady Bernoulli.

GIVEN tank drainage time:
Instantaneous energy + tank mass balance.

UNIVERSAL PROCESS
Sketch -> choose axes and stations -> state assumptions -> full equation -> justify vanished terms -> solve symbolically -> check dimensions, signs, physical trend.
