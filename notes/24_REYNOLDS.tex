Reynolds and Entrance

ROUND PIPE REYNOLDS NUMBER
$$Re_D=\frac{\rho\bar VD}{\mu}$$
$$Re_D=\frac{\bar VD}{\nu}$$
$$Re_D=\frac{4Q}{\pi D\nu}$$
$$Re_D=\frac{4\rho Q}{\pi D\mu}$$
$$Re_D=\frac{4\dot m}{\pi D\mu}$$

ROUND-PIPE CLASS THRESHOLDS
Re < approx 2300 laminar.
2300-4000 transitional.
Above 4000 turbulent.
Not universal for plate/film/external flow.

LAMINAR ENTRANCE LENGTH
Class lecture convention:
$$L_e\approx 0.06Re_D D$$
(Some references use 0.05 instead.)
Fully developed means profile NOT changing downstream; velocity is not uniform across pipe.

LARGEST ESTIMATED LAMINAR FLOW
Given Recrit:
$$\bar V_{max}=\frac{Re_{crit}\nu}{D}$$
$$Q_{max}=\frac{\pi D\nu Re_{crit}}{4}$$
Horizontal laminar pressure gradient:
$$\frac{dp}{dx}=-\frac{128\mu Q}{\pi D^4}$$
Check units and use properties at actual temperature.

IN PIPE PROBLEMS
Find Q and V -> Re -> choose correct model -> verify assumption afterward.
